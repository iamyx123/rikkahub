# RikkaHub 3.1.0-custom.20261023.1

- 账号、登录、课程资料和管理面板沿用原生分组列表、表单和对话框，移除粗边框与重复卡片。
- 默认班级使用原生单选列表，整行可选；管理员和普通账号继续按服务器权限使用全部已有功能。
- 控制面板按中文分类查找功能；接口路径、原始字段和完整请求内容收进高级详情。

- 保留共享 Root 会话、MCP 令牌刷新、Class Record 登录恢复和 Android 14 部分照片访问等稳定性修复。

保留原包名和签名，支持直接覆盖安装。旧版发布文件、登录配置、数据及原有定制功能均保留。
