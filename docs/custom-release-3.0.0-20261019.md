# RikkaHub 3.0.0-custom.20261019

版本号 194，包名 me.rerere.rikkahub.debug，ARM64 releaseDebug；沿用既有定制版签名。上游仍为 07b1238a8afa50da8de3dca1feac871d22721698（正式 3.0.0 及其后 3 个提交），保留学习桌面、墨水屏、手势、相机、书签、截图服务、打印和导入。

本次补齐原生交互 UI：57 个组件、59 个本地函数，新增分页轮播、弹出详情、链接、列表项、图标按钮、可点击区域、计时器、图片搜索、图标、地图标记和静态完成提示；1,671 个 Lucide 图标按需加载。地图支持点击加载街道瓦片及驾车道路概览，图片搜索保留来源。散点图使用数值横轴。图片/打印导出保存状态并绘制图表、SVG 和表单值。

每个对话在输入栏独立选择“交互 UI”，默认关闭。中途开关只在下一条新用户消息追加不可变提醒，不改开头 system 或之前的请求内容。生成期间不能切换；关闭后历史卡片仍显示、可操作。因为部分服务商不接受中途 SYSTEM 角色，提醒实际放在对应用户轮开头，以保持跨服务商兼容。缓存是否命中仍由服务商决定。

墨水屏思考区只显示“正在思考”，无读秒；卡片无动画，倒计时静态显示“计时中”，到期更新一次。Android 使用 Compose 与共享 QuickJS，不新增 WebView；本次不支持 YouTube/音视频和 HtmlView 任意网页/JavaScript。原生参数协议与上游 React 包并非所有位置参数完全一致。组件范围和开销见 [接入说明](open-intelligent-ui-plan-20261018.md)。

最终构建、JVM、JavaScript、网页类型检查、Lint、APK 签名/16 KB 对齐与 NAS 哈希结果见发布目录 verification.json 和 BUILD-INFO.txt。浏览器使用组件测试页，保存接口为测试实现，公共图片/地图接口实际联网；不等于 Android HTTP 服务或手机验收。未使用模拟器、未安装设备；真实模型遵循格式、整机内存峰值、墨水屏物理刷新、相机、截图服务和蓝牙打印尚未实测。
