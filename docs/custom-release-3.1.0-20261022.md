Class Record 入口位于聊天加号菜单，与 MCP 服务器并列。账号使用学校原有身份，服务器校验学校、班级、角色和资料权限。默认班级按服务地址和账号分别保存，AI 在未指定其他范围时使用它；明确指定课程、资料或其他班级时不套用当前默认班级。

使用时在“＋ → Class Record → 账号”登录，选择默认班级，并开启“允许 AI 调用 Class Record”。此开关随当前对话保存；新建对话沿用助手设置。原有 MCP、模型供应商和搜索服务的配置继续保留，Class Record 学校登录单独管理。需要把下载文件交给工作区处理时，先在加号菜单绑定工作区。

“课程与资料”支持下一页和读取全部后续页，完整转写读取后可将已读取内容加入聊天。交互界面开关旁的齿轮可编辑附加提示词、查看默认语法或恢复默认；保存后从下一条用户消息起生效。

“最新教室截图”按定时截图实际拍摄时间取最新记录，不依赖课程匹配，不混入展台图片、课件批注或手动截图。它代表已保存的画面，不代表实时摄像头。普通账号仍受原有资料开放权限限制。

文件流式下载并校验大小和 SHA-256，可加入聊天或导入当前工作区；工作区导入失败时保留已下载的本机附件。文档可在本机分页提取，已有录音原话和人工校订文本从服务器完整转写读取。重新转写、重新整理和发布由明确的管理操作触发。

原生控制面板根据当前账号可用的管理接口生成表单和结果，具体操作继续执行原有服务端授权。AI 读取可直接调用，修改操作进入应用已有的工具审批流程。登录密码不保存；记住登录状态使用设备密钥加密，并排除备份。

交互界面的上游仓库和语言核心已重新核对；其当前版本仍与此前基线相同，本次修复本地适配。表单和按钮沿用应用原生组件。开启模式、自定义提示词的变化以及交互变量快照在下一条用户消息发送时记录，不改写旧消息。关闭模式后历史交互界面继续可用。

右上角月亮图标是阅读省电开关，默认关闭；短按切换，长按设置整数等待秒数。默认 30 秒，范围 0–3600 秒，0 表示立即执行。只在前台浏览已完成回答且没有生成、语音或网络任务时开始计时，发送下一条消息前先恢复联网；流式回答、下载等实际网络请求持有占用，完成后重新计时。进入后台、离开回答或关闭开关时恢复本功能改变的飞行模式；用户原本已开飞行模式时不代为关闭。

自动控制飞行模式需要 root 授权。应用使用固定系统命令，并读回真实系统状态确认结果；无权限或系统不支持时显示错误。恢复记录保存在不参与备份的本机目录，异常退出后下次启动先尝试恢复。顶部不逐秒刷新，设置弹窗内才更新倒计时，避免墨水屏无谓刷新。尚未进行真机飞行模式、无线恢复和耗电量验收。

构建与包校验结果以本次发布目录 `verification.json`、构建日志和服务端公网验收报告为准。无已连接的 Android 设备，不使用模拟器；签名与构建检查不等于真机安装、物理墨水屏刷新、相机或蓝牙打印验收。

发布前公网复查时，服务端已由并行维护升级至 `0.2.85+20261022-console-performance-r2`，本次原生兼容接口保留，12 个读取工具和 199 项管理操作的目录均验证通过；真实课程、完整转写、资料分页和原件大小、SHA-256、HEAD、Range 下载校验通过。该复查为读取验收，未逐项执行生产管理修改；非管理员权限由隔离 HTTP/数据库回归验证，未新建生产账号。

构建入口为 `scripts/build-custom.ps1`，Gradle、包管理和临时缓存固定放在 D 盘。旧缓存删除受到自动审批拦截的部分单独记录，未将“准备了清理脚本”计为已经清理。
