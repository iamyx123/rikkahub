# RikkaHub 3.0.0-custom.20261018

版本号 193，包名 me.rerere.rikkahub.debug，ARM64 优化 releaseDebug 构建。发布流程从 10 月 18 日延续至 19 日，保留既定版本标识。

同步上游 master 至 07b1238a8afa50da8de3dca1feac871d22721698，包含正式 3.0.0（55a108a4）及其后 3 个提交。合并提交 0a252078，迁移前备份分支 backup-before-upstream-3.0.0-20261018。

新增会话独立的“交互 UI”开关，默认关闭；启停仅在下一条消息前追加不可变提醒，历史交互卡片保留。Android 原生 Compose + QuickJS 支持输入、计算、问答、表格、图表与矢量图，网页端复用同一解析协议。没有新增 WebView 或 YouTube/视频组件。墨水屏只显示“正在思考”，不再读秒，并停用相关动画。

保留学习桌面、墨水屏设置、书签、打印、导入、截图服务器，以及单击截图/双击系统相机/长按配置。兼容全屏正文和思考编辑器的静态光标，上游新增转场在墨水屏模式关闭。其余定制保留审计见 preservation-audit.json。

使用方法：打开对话，在输入栏点击“交互 UI”后发送新消息，例如“做一张可以选择答案的复习卡”或“用输入框和滑杆做费用计算器”。关掉开关后，新消息要求普通 Markdown；先前卡片依然可查看、修改、重置。卡片“继续讨论”动作只填写草稿，不自动发送。

完整组件范围、资源限制、提示词成本、状态存储和导出边界见 [原生接入说明](open-intelligent-ui-plan-20261018.md)。地图是坐标概览，图片按需加载；打印提供变量与源码静态记录。

最终测试、签名、ZIP 对齐、APK 哈希与 NAS 副本核验记录在同目录的 verification.json / BUILD-INFO.txt。签名须与既有 2.5.6-dev.20261018 定制版一致后才发布，可直接覆盖升级。旧 APK 和源码备份保留。

构建、单元测试和本地浏览器验收不代表手机安装验收。未使用模拟器、未安装到设备；实际模型输出、墨水屏内存/刷新、系统相机、截图服务和蓝牙打印仍需真机确认。
